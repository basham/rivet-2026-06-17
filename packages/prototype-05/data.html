How each page is assembled, and the field names used throughout the content spec below.

How to use this document

  • Every page is listed under its site map number. Child links are not repeated here — pull them from sitemap.md, since the sidenav and list-hub are always just "this page's children in order."
  • Copy is generic on purpose. It reads as real zoo content so participants engage with the labels, but nothing is factually load-bearing.
  • Anything in {curly braces} is a placeholder the design itself leaves unfilled (statistics, dates). Leave the braces visible in the prototype — the Figma file does.
  • Image lines are art direction, not alt text. Any stock photo matching the description works; the navigation is what's being tested.
